# Cricket Performance Analysis and Match Prediction System

This project predicts IPL match results using machine learning 
and provides team performance analysis.

## Features
- Match winner prediction
- Head-to-head comparison
- Team performance analysis
- Top batsman and bowler stats
- Strike rate and economy analysis

## How to Run
1. Download the dataset
2. Place matches.csv and deliveries.csv inside 'ipl dataset' folder
3. Run the app using:
   streamlit run app.py

## Note
Dataset is not included due to GitHub size limits.

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
